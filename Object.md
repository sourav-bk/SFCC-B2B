# Object 

Salesforce objects are digital containers or database tables that store and organize business data on the Salesforce Platform.

- Core componect :
  - Object - database table
  - Record - table row
  - Field - table column
 
- **Main Types of Objects**

Salesforce objects are mainly categorized into four types:

| Object Type | Description | Examples |
|-------------|-------------|------------|
| Standard | Objects provided by Salesforce out of the box | Account, Contact, Lead, Opportunity, Case |
| Custom | Objects created by developers/admins for specific business needs | Employee__c, Project__c, Invoice__c |
| External | Objects whose data present outside Salesforce and is accessed via Salesforce Connect | SAP Customer, External ERP Orders |
| Platform Events | Event-based objects used for asynchronous communication and integrations | Order_Event__e, Payment_Event__e |

|----------|----------|

| Lead | Potential Customer |
| Opportunity | Sales Deal |
